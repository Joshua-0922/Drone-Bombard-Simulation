 4. 진짜 원인 (결정적 finding)
================================================================================

  Initial position log 로 실측한 fact:
    - 정책 시작 시점 target xy 거리 = 5.10m (mean, min 5.00 ~ max 5.23)
    - Drone spawn (0, 0, 0) → Target (4, 3, 0) 직선 거리 = 5.0m
    - Cruise 로 이동 미미 (0.15m 정도)

  Stage 조건 vs 시작 거리 매칭:
    ┌─────────────┬────────┬──────────────────┬───────────────┐
    │ Stage       │ Radius │ Spawn d²≈25      │ 학습 유도?    │
    ├─────────────┼────────┼──────────────────┼───────────────┤
    │ stage1_intro│ 6.0m   │ 안 (여유 11)     │ ✗ trivial     │
    │ stage2_close│ 5.5m   │ 안 (여유 5.25)   │ ✗ trivial     │
    │ stage3_target│ 4.53m │ 밖 (부족 4.5)    │ ✓ 유일 학습   │
    └─────────────┴────────┴──────────────────┴───────────────┘

  결론:
    - Stage1/2 는 정책이 아무것도 안 해도 성공하는 조건 (trivial)
    - 정책은 stage1/2 에서 이동 학습을 배우지 않음
    - Stage3 에서 처음 이동 필요 → 능력 부재 → 완전 실패
    - 실제 학습해야 할 이동거리 = 5.0m - 4.53m = 0.47m (매우 짧음)

 6. 개발된 인프라 (재사용 가능)
================================================================================

  6-1. Self-healing SAC (DampedEntropySAC 확장)
    - A1: gradient clipping (actor max_norm=20, critic max_norm=200)
    - B3: weight NaN detection + snapshot rollback
    - 상세 metric (Q values, weight/grad norm, log_prob, reward batch stats)
    - Metric: train/nan_rollback_count, actor_grad_clip_hit, critic_grad_clip_hit

  6-2. Curriculum + Regression 시스템
    - 5-stage 자동 progression
    - Window-based success rate 판정 (10k window, 0.95 threshold)
    - Regression: 이전 stage 자동 복귀 (30% threshold, 20k cooldown)
    - Log: CURRICULUM_ADVANCE / CURRICULUM_REGRESS

  6-3. Initial position 실측 도구
    - Ep 첫 step 위치/속도/거리 정보를 info 에 저장
    - Callback (TerminalTypeMonitor) 이 rolling stats (100 ep) → WandB
    - Metric: env/initial_target_dist_3d_{mean,min,max}, initial_pos_{x,y,z}_*
    - **근본 원인 파악의 결정적 도구**

  6-4. Terminal type monitor
    - 매 ep terminal_type 분류: crash / entry_success / entry_partial_fail /
      bad_att_{ang_vel,inverted,tilt} / trunc_{timeout,out_of_range,overspeed,
      max_altitude,hover_timeout,sphere_escape}
    - Rolling window rate → WandB
