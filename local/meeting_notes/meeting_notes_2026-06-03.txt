********************************************************************************
*  PART 2 — 근본 원인 정밀 분석 (Bounded Action + Target Entropy)
********************************************************************************

  사용자 질문: "결국 action이 [-1,1] bounded되어서 그런 거야?"
  → 정확한 진단. 이게 핵심.

  SAC 자동 entropy 튜닝 메커니즘:
    ent_coef_loss = -(log_alpha * (log_prob + target_entropy).detach()).mean()
    d_loss / d_log_alpha = -(log_prob + target_entropy)

    log_prob > -target_entropy 이면 alpha ↑
    log_prob < -target_entropy 이면 alpha ↓

  Bounded action space (tanh squash) 의 특성:
    a = tanh(N(μ, σ²))
    log π(a|s) = log N(u|μ,σ) - Σ log(1 - tanh²(u_i))
                  가우시안 부분  - Jacobian 보정

    Jacobian 보정이 자연스럽게 큰 양수 (action이 ±1 근처)
    → log_prob가 일반적으로 큰 양수
    → log_prob > 5는 정상 학습 시에도 흔함

  target_entropy = -5 (default = -|A|) 의 문제:
    -target_entropy = 5
    log_prob > 5 → alpha ↑ 압력 거의 항상
    → 학습 진행될수록 ent_coef 계속 증가
    → hard cap에 갇힘

  비유:
    "중력이 위쪽으로 작용하는 세계 + 천장(cap)"
    → 천장에 영원히 붙음 ← Round 6 v2

  해결: target_entropy = -15
    -target_entropy = 15
    log_prob > 15는 매우 극단적 (거의 발생 X)
    → 대부분 alpha ↓ gradient
    → cap 안 닿거나 닿아도 자기 복구

  비유:
    "중력이 아래쪽으로 작용하는 세계 + 천장(cap)"
    → 가끔 위로 튀어 올라도 다시 내려옴 ← Round 7 예상
