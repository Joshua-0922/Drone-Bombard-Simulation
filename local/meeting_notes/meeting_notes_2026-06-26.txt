********************************************************************************
*  PART 7 — w_dist 정확한 의미 + payload tracking 분석
********************************************************************************

  사용자 질문: "w_dist는 target에 드론이 가까워질수록 패널티를 주는거야?"

  Claude 답:
    아니요. **정반대**.
    r3_dist = w_dist * (d_xy_prev - d_xy)
    - 가까워지면 (delta > 0) → +reward
    - 멀어지면 (delta < 0) → -penalty
    → target 가까이 가도록 유도. v8 의 toss 가 marker 지나친 후 멀어지는 부분에서
       -penalty 받음.

  사용자 질문: "혹시 payload를 추적할 수는 없는거야?"

  Claude 답 (현재 시스템):
    1. 매 step: ballistic 예측 (drone vel + alt) → w_impact * exp(-k * d_impact) reward
       (실제 측정 X, 예측만)
    2. Drop 시점: drop_calculator 가 Gazebo payload contact 감지 → actual landing
       위치 → drop_err → terminal reward
    3. Drop 직후: 추적 안 함 (ep 즉시 종료)

    → 사용자 의도 "처음부터 끝까지 payload" 의 detach 후 부분 미반영.

    구현 옵션:
      옵션 A — Gazebo payload pose 직접 받기
      옵션 C — detach 후 ep 연장
      옵션 A + C = 사용자 의도 100% (Issue #027)
