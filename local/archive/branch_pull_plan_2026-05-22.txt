────────────────────────────────────────────────────────────────────────
 2-4. 우리 변경분 vs 새 branch — 3가지로 분류
────────────────────────────────────────────────────────────────────────

  (A) 새 branch 에 이미 있는 우리 변경 → re-apply 불필요
      예: speed_gate 가 이미 적용되어 있을 수도

  (B) 새 branch 에 없는 우리 변경 → re-apply 필요
      예: w_impact=8 같은 hyperparameter 결정

  (C) 새 branch 의 새 기능 → 채택 여부 결정
      예: 새 branch 가 추가한 신호, 새 reward 항 등

각각 항목별로 의사결정.
