 1. 배경 및 목표
================================================================================

현재 학습은 절대 좌표 기반:
  - 드론이 자기 절대 위치 (x, y, z) 알고 있음
  - X마커 절대 위치 (11, 10) env가 제공
  - agent가 "(11, 10)으로 가" 학습 — 사실상 navigation

실제 배포 시나리오:
  - 드론은 자기 절대 위치 모름 (GPS만으론 정확도 부족)
  - X마커 위치 사전 미지
  - 카메라로 마커 감지 → 상대 위치/각도 학습

최종 목표:
  - 카메라 시뮬레이션 활성화
  - 절대 위치 의존성 완전 제거
  - vision-based pursuit 학습

이번 라운드 (Round 5 후보):
  - 카메라 시뮬레이션은 활성화 X
  - env 내부는 절대 위치 유지 (CCIP, 물리 계산용)
  - 그러나 agent obs는 "카메라가 본 것처럼" ground truth 상대값만 사용
  - 점진적 전환 단계 — agent가 상대 좌표 학습 적응

 2. 합의된 설계 원칙
================================================================================

  a) Body frame 사용
     - 드론 yaw 회전에 따라 obs 변함
     - 카메라 시야 기반과 일치
     - rel_x_body (전방+), rel_y_body (좌측+)

  b) 고도 z는 obs에 유지
     - 기압계 + GPS + IMU로 측정 가능 (실제 드론)
     - 카메라와 무관하게 알 수 있는 정보
     - 단, 절대 (x, y)는 제거

  c) FOV 160° (양쪽 80°)
     - 광범위한 시야 (광각 카메라 가정)
     - bearing |angle| > 80° → 시야 밖

  d) FOV 밖 처리
     - 어떤 방식으로 agent에게 "타겟 안 보임" 신호 줄지 결정 필요
     - 시야로 돌아오게 하는 학습 신호 필요

 4. 제안된 obs 구조 (17D 유지 안)
================================================================================

  현재 obs (17D):
    [0-2]   드론 절대 위치 (x, y, z) / 50m
    [3-5]   속도 / 15m/s
    [6-8]   ang_vel / π
    [9-11]  vision (synthetic u, v, conf)
    [12]    payload attached
    [13-14] rel_target (world frame) / 50m
    [15]    d_impact / 50m
    [16]    t_f / 10s

  제안 obs (17D, 같은 차원):
    [0]     드론 고도 z / 50m              ← 기압계 측정값
    [1-3]   속도 / 15m/s                    ← IMU + GPS
    [4-6]   ang_vel / π                     ← IMU
    [7-9]   vision (synthetic) — 카메라 대비 보존
    [10]    payload attached
    [11-12] rel_target_body / 50m           ← 카메라 시뮬레이션
    [13]    bearing / π                     ← 카메라 수평 각도
    [14]    target_alt_diff / 50m           ← (z_target - z_drone)
    [15]    d_impact / 50m                  ← env 계산 (CCIP)
    [16]    t_f / 10s                       ← env 계산

  핵심 변경:
    - [0-2] 절대 (x, y, z) → [0] 고도 z만 (x, y 제거)
    - 제거된 2 dim → bearing + target_alt_diff 추가
    - [13-14] world frame → body frame
    - 차원 동일 → 코드 호환 가능

 5. Body frame 변환 공식
================================================================================

  ```
  dx_world = target_x - drone_x
  dy_world = target_y - drone_y
  yaw = drone.yaw

  rel_x_body =  dx_world * cos(yaw) + dy_world * sin(yaw)  # 전방+
  rel_y_body = -dx_world * sin(yaw) + dy_world * cos(yaw)  # 좌측+
  bearing = atan2(rel_y_body, rel_x_body)  # [-π, π]
  distance = sqrt(rel_x_body² + rel_y_body²)
  ```

  드론 yaw에 따라 obs 변함 — 동일 위치 타겟도 yaw 다르면 다르게 보임.
