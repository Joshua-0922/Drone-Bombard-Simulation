================================================================================
 1. 문제점
================================================================================

  v9a (`phase1_redux_v9a_payload_dist_angaccel`, run zjexq20k) 의 fine-tune
  진행이 17k step 만 (의도 100k 의 17%) 으로 처방의 본질 효과 부족.

  처방:
    - w_dist: 1.0 → 1.5 (payload distance reward 강화)
    - drop_angaccel_penalty_scale: 0.5 NEW
    - drop_angaccel_window_n: 5 NEW

  5 ep 평가 결과 (preempt step 313k):
    - success 80% (v8 동일)
    - mean err 1.89m (v8 1.85 와 거의 동일)
    - max ang_vel 2.10 rad/s (v8 2.5 대비 -16%) ← 처방 1 효과만 명확

  → drop_angaccel penalty 효과 측정 가능, w_dist 1.5 효과 미미.
  → 정책의 toss 전략 그대로 유지 (사용자 의도 달성 안 됨).


================================================================================
 2. 분석
================================================================================

  2-1. v9a 의 처방 magnitude vs v8 baseline reward:

  v8 평균 terminal reward = +30 ~ +80 per ep
  v9a 의 처방 영향:
    - w_dist 1.5 의 누적 (50 step 비행): +5 (지나치는 시점 -1.4 포함 → 순 +3.6)
      = terminal +30 의 ~12%
    - drop_angaccel penalty 0.5 × max_accel 2 rad/s² = -1.0 per ep
      = terminal +30 의 ~3%

  처방 총 영향 = +2.6 (terminal 의 8.7%)
  → 17k step 으로는 정책 본질 변경 어려움.

  2-2. v8 의 강한 toss prior (303k 학습):
    - 정책이 학습한 toss = 모든 ep 마다 동일 (deterministic 모드)
    - critic network 가 toss trajectory 의 high reward 확신
    - actor network 가 toss action sequence 강하게 학습
    - fine-tune 의 작은 처방 신호가 이 prior 흡수

  2-3. fine-tune step 수의 효과 curve (예상):
    - 0 ~ 10k:    정책 초기 흔들림 (adapter loss spike)
    - 10k ~ 50k:  새 reward 적응 시작
    - 50k ~ 100k: 본질 행동 변화 가능
    - 100k +:    new local optimum 정착

  v9a 의 17k 는 0~10k 흔들림 직후. 본질 변화 시작 전.

  2-4. 학습 monitoring 의 trace:
    | 시점     | step   | success_rate | ep_rew | ep_len | actor_loss |
    |---------|--------|--------------|--------|--------|------------|
    | 3h      | 234k   | 0.51         | -50    | 47     | 60-80      |
    | 4h      | 296k   | 0.55         | -43    | 40     | 29-33      |
    | 4.8h    | 303k   | 0.54         | -37    | **6.27** | 22-35   |
    | 5h      | 313k   | 0.58         | -15.5  | **96.3** | 35.1   |

    - actor_loss 큼 → 정책 변화 강함
    - 4.8h ep_len 급락 (47→6) → 정책 발산 의심
    - 5h 회복 (96.3) → 적응 마무리
    - SIGTERM stop

 3. 권장 처방
================================================================================

  3-1. fine-tune step 수의 권장 범위:
    - **최소 50k step** (v8 baseline 303k 의 16.5%) — 처방 본질 효과 보이려면
    - **권장 100k step** (33%) — 안정 신뢰성
    - **최대 200k step** (66%) — 완전 새 정책 가능

  3-2. v9a 의 옵션:
    A. v9a preempt 에서 추가 학습 (resume) — 83k 더 진행 (~12-18시간)
    B. fresh start with stronger shaping (v9b) — 처방 scale 증가
    C. v9a 폐기 + 다른 처방 (#026 의 두번째 처방 도입)


================================================================================
 4. v9a 결과의 의미
================================================================================

  비록 본질 행동 변화 안 됐지만 다음 검증됨:
    - drop_angaccel penalty 효과 명확 (16% ang_vel 감소)
    - 처방 코드 정상 작동
    - 5 ep 평가 80% success 유지 → fine-tune 안전성 입증
    - SIGTERM preempt save → replay buffer 재사용 가능

  교훈:
    - "warm start + 처방 추가" 의 효과 = step 수에 비례
    - 작은 step (17k) 으로는 효과 측정만 가능
    - 본질 변경 원하면 100k+ step or stronger shaping
