================================================================================
 Issue #005 — Replay Buffer 초기 데이터 오염
================================================================================
생성일 : 2026-05-25
상태   : 보류 (500k+ 학습 시 재검토)


================================================================================
 1. 문제점
================================================================================

buffer_size = 500k. 학습 초기의 랜덤 탐색 데이터가 buffer에 오래 남아있다.
정책이 개선된 후에도 초기의 나쁜 경험(랜덤 비행, crash)에서 계속 학습.

큰 buffer는 catastrophic forgetting 방지에 유리하지만,
정책 전환(예: "접근만" → "정밀 drop") 시 적응 속도가 느려진다.


================================================================================
 2. 트레이드오프
================================================================================

  buffer 크면 (500k):
    + 안정적 학습, forgetting 방지
    - 초기 쓰레기 데이터 잔존, 적응 느림

  buffer 작으면 (100k):
    + 최근 경험 위주 학습, 빠른 적응
    - 드문 이벤트(drop 성공) 경험이 빨리 사라짐

  현재 200k 학습에서 buffer 500k면 전체 학습 데이터의 40%만 유지.
  150k 학습이면 전체가 buffer 안에 들어감 — 오염 문제 없음.
