================================================================================
 Issue #003 — CCIP 예측 오차와 실제 착탄 오차의 갭
================================================================================
생성일 : 2026-05-25
상태   : Round 1 후 데이터 분석


================================================================================
 1. 문제점
================================================================================

auto_drop이 d_impact ≤ 10m에서 발동하지만, 실제 착탄 오차는 9~15m.
CCIP 예측값보다 실제가 항상 나쁘다.

CCIP 모델은 단순 운동학(중력만, 공기저항/바람 없음):
  t_f = (vz + sqrt(vz² + 2gz)) / g
  x_p = x + vx * t_f
  y_p = y + vy * t_f

Gazebo 물리 엔진은 공기저항, 관성, 드론 자체의 기류 영향 등을
포함하므로 예측과 실제 사이에 체계적 오차가 발생.

에이전트가 d_impact을 아무리 최적화해도 CCIP 자체의 한계 때문에
실제 정밀도에 상한이 존재할 수 있다.


================================================================================
 2. 확인 필요 사항
================================================================================

  - drop 에피소드에서 d_impact(예측)과 drop_error(실제)의 상관관계
  - 체계적 편향인지 (항상 실제 > 예측), 랜덤 노이즈인지
  - 비행 속도/고도에 따라 갭이 달라지는지
  - CCIP 모델 개선 (공기저항 항 추가) 이 필요한 수준인지

 5. RESOLVED — 진짜 root cause 발견 (2026-06-07)
================================================================================

이 issue 의 모든 가설 (velocity inheritance failure, 옵션 A, G-a, G-b)
이 잘못된 진단 위에 쌓였음. 진짜 root cause 는 별개:

  payload_0~3/model.sdf 의 OdometryPublisher 가 <dimensions> 미지정
  → gz-sim8 default = 2 (2D mode)
  → payload odom 의 z 좌표가 항상 0 으로 publish
  → drop_calculator 가 payload_z ≤ 0.04 시 즉시 impact 처리
  → drop_error = drone 의 분리 시점 horizontal 위치 (= d_xy_at_trigger)

상세는 issue_023_payload_odom_2d_bug.md 참조.

[v3 의 모든 통계 재해석]
  drop_error ≈ d_xy        → 분리 즉시 ground 판단의 artifact
  gap mean 1.73m           → d_xy - d_impact (의미 없는 값)
  correlation 0.955        → speed 클수록 drop trigger 시 d_xy 큼 (statistical)
  옵션 A 의 16% 감소       → measurement noise 안의 변동

[v4 결과 (188 drops) 재해석]
  drop_error mean 3.585m   → v3 와 동일 (artifact 그대로)
  gap 1.46m, corr 0.849   → 부분 변화는 noise 안에서
  → 옵션 A 의 효과는 사실상 없었음

[Fix 후 검증 (test_v1, 2026-06-07)]
  payload first sample z = 5.33m (이전: 0)
  자유낙하 → 1.0s 후 ground 도달
  velocity transfer ratio 103.1%
  → drop_error 가 진짜 ground impact 측정

[처방 정리]
  - 옵션 A 코드 제거 (drone_drop_env.py 의 wrench_pub, publish_drop 의 wrench 부분)
  - ApplyLinkWrench plugin 제거 (world SDF)
  - bridge config 의 wrench topic 제거
  - DROP_SKIP_WRENCH toggle 제거
  - w_verify.csv 로깅 제거 (drop_calculator)
  - w_prediction = 0 (gap reward 비활성 — fix 후 gap≈0)
