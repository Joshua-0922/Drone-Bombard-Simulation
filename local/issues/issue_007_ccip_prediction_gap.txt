 Issue #003 — CCIP 예측 오차와 실제 착탄 오차의 갭

생성일 : 2026-05-25
상태   : Round 1 후 데이터 분석


================================================================================
 1. 문제점
================================================================================

auto_drop이 d_impact ≤ 10m에서 발동하지만, 실제 착탄 오차는 9~15m.
CCIP 예측값보다 실제가 항상 나쁘다.

CCIP 모델은 단순 운동학(중력만, 공기저항/바람 없음):
  t_f = (vz + sqrt(vz² + 2gz)) / g
  x_p = x + vx * t_f
  y_p = y + vy * t_f

Gazebo 물리 엔진은 공기저항, 관성, 드론 자체의 기류 영향 등을
포함하므로 예측과 실제 사이에 체계적 오차가 발생.

에이전트가 d_impact을 아무리 최적화해도 CCIP 자체의 한계 때문에
실제 정밀도에 상한이 존재할 수 있다.


================================================================================
 2. 확인 필요 사항
================================================================================

  - drop 에피소드에서 d_impact(예측)과 drop_error(실제)의 상관관계
  - 체계적 편향인지 (항상 실제 > 예측), 랜덤 노이즈인지
  - 비행 속도/고도에 따라 갭이 달라지는지
  - CCIP 모델 개선 (공기저항 항 추가) 이 필요한 수준인지
