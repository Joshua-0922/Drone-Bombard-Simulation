================================================================================
 1. 문제점
================================================================================

drop 발동 시 DetachableJoint가 물리적으로 파괴됨.
다음 에피소드 reset에서 joint 복원 불가 → Gazebo + PX4 전체 재시작 필요.
소요 시간: ~30초 (drop 미발생 reset은 텔레포트 ~2초).

hybrid drop(#006) 적용으로 drop 빈도가 높아지면 학습 속도 체감 저하 예상.


================================================================================
 2. 현재 동작
================================================================================

  drone_drop_env.py reset():
    if _prev_dropped:
        _kill_infra()     # Gazebo + PX4 전부 종료
        _start_infra()    # 처음부터 재시작 (~30초)
    else:
        _gz_reset_poses() # 빠른 텔레포트 (~2초)


================================================================================
 3. 개선 방안 후보
================================================================================

  a) Gazebo world reset API
     gz service /world/reset 으로 joint 포함 전체 초기화
     이전 시도: ODE AABB integer overflow crash 발생으로 포기

  b) DetachableJoint 동적 재생성
     Gazebo Harmonic ECM API로 joint만 재생성
     가능하면 ~2초로 단축
     구현 복잡도 높음

  c) 물리 drop 생략
     CCIP 예측값을 actual_error로 사용, 실제 낙하 시뮬레이션 건너뜀
     가장 빠르지만 Issue #007 (CCIP 갭) 미해결 시 정확도 저하
