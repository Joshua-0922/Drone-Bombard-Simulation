 Issue #020 — CheckpointCallback 정렬 버그 (최신 체크포인트 즉시 삭제)

상태   : 해결됨 (Round 6 v2)


================================================================================
 1. 문제점
================================================================================

학습 진행 중 일정 step (예: 95k) 이후 새 체크포인트가 저장되지 않음.
실제로는 5k 간격으로 저장되지만, 즉시 cleanup callback이 삭제.

증상:
  Round 3 lidq3ydu 학습 중 95k까지 저장 후 더 이상 누적 안 됨
  Round 6 v1 (bfv4la9a) 95k까지 저장 후 동일 현상
  마지막 5개 체크포인트: 75k, 80k, 85k, 90k, 95k (이후 누적 X)


================================================================================
 2. 원인 분석
================================================================================

CleanupOldCheckpointsCallback 코드:
  ```python
  files = sorted(_glob.glob(
      os.path.join(self._dir, f'{self._prefix}_*_steps.zip')))
  for old in files[:-self._keep]:
      os.remove(old)
  ```

문제: `sorted()`가 알파벳순 정렬

알파벳 순서:
  '0' < '1' < ... < '9'

체크포인트 파일명 정렬:
  sac_drop_100000_steps.zip  ← '1'로 시작
  sac_drop_105000_steps.zip
  sac_drop_110000_steps.zip
  ...
  sac_drop_75000_steps.zip   ← '7'로 시작
  sac_drop_80000_steps.zip
  sac_drop_85000_steps.zip
  sac_drop_90000_steps.zip
  sac_drop_95000_steps.zip

새 100k가 생성됨:
  - files = [100k, 75k, 80k, 85k, 90k, 95k]  (정렬 순)
  - files[:-5] = files[:1] = [100k]  ← 100k가 처음
  - 100k 삭제됨!

결과:
  - 100k+ 새 체크포인트가 생성 즉시 cleanup으로 삭제
  - 75k~95k의 오래된 5개만 영구 보존
  - 학습 95k 이후의 모델 가중치 손실


================================================================================
 3. 해결
================================================================================

step 번호 기반 정렬로 변경:

  ```python
  files = _glob.glob(
      os.path.join(self._dir, f'{self._prefix}_*_steps.zip'))
  def _step_num(p):
      name = os.path.basename(p)
      try:
          return int(name.replace(f'{self._prefix}_', '').replace('_steps.zip', ''))
      except ValueError:
          return -1
  files = sorted(files, key=_step_num)
  for old in files[:-self._keep]:
      os.remove(old)
  ```

이제:
  - 파일명에서 step 번호 추출하여 정수 기준 정렬
  - files[:-5]가 시간순 옛 것을 가리킴
  - 100k+ 새 체크포인트 정상 보존
