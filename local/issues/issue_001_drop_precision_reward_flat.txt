================================================================================
 Issue #001 — Drop 정밀도 보상이 거리에 둔감
================================================================================
생성일 : 2026-05-24
상태   : 적용 예정 (Round 1)
관련   : junsang_v4_150k 학습 (WandB run wdwoim34, xk7rw5e1)


================================================================================
 1. 문제점
================================================================================

학습 중 drop은 충분히 발생하지만 (19k step에서 55회) total_success_count = 0.
drop_error 분포가 4~35m 범위에 머물며 0.5m 이하로 개선되지 않는다.

원인: 현재 보상 구조에서 drop 거리에 따른 보상 차이가 너무 작다.

  현재 공식:
    reward = 150 (drop_attempt_bonus)
           + 100 * exp(-0.3 * d_error)   (precision)
           + 100 (jackpot, d_error ≤ 0.1m)

  거리별 보상:
    15m → 151    10m → 155    5m → 172    1m → 224    0.5m → 236

  15m와 5m의 차이가 21밖에 안 된다.
  drop_attempt_bonus=150이 지배적이라 "대충 drop만 하면 +150 확보" 전략이 최적.


================================================================================
 2. 분석
================================================================================

보상에 영향을 주는 파라미터 3개:

  a) drop_attempt_bonus (현재 150)
     — drop 시도 자체에 대한 고정 보상
     — 높을수록 정밀도와 무관하게 drop만 유도
     — 너무 낮추면 agent가 drop 자체를 안 하게 될 위험

  b) k2_precision (현재 0.3)
     — exp(-k2 * d_error)의 감쇠 상수
     — 높을수록 가까운 거리에서만 보상이 큼 (sharp)
     — 너무 높으면 현재 수준(10~15m)에서 기울기가 0에 수렴 → 학습 신호 없음

  c) w_drop_base (현재 100)
     — precision 항의 가중치
     — 높을수록 거리별 보상 차이의 절대값 증가
     — drop_attempt_bonus 대비 비중이 커져야 의미 있음

핵심 트레이드오프:
  - k2를 높이면 정밀 구간(0~2m)의 기울기는 강해지지만
    원거리(5m+)의 기울기가 사라져 "10m→5m" 개선 동기가 없어짐
  - drop_attempt_bonus를 낮추면 정밀도 비중은 올라가지만
    agent가 drop 시도 자체를 꺼릴 수 있음


================================================================================
 3. 해결 방안 후보
================================================================================

--- 방안 A: 세 파라미터 동시 조정 (공격적) ---

  drop_attempt_bonus : 150 → 50
  k2_precision       : 0.3 → 0.5
  w_drop_base        : 100 → 300

  거리별 보상 (방안 A):
    15m → 50     10m → 52     5m → 75     2m → 160    1m → 232
    0.5m → 283   0.1m → 336 (+100 jackpot = 436)

  장점: 10m→5m 기울기 존재 (52→75), 5m→1m 급격한 상승 (75→232)
  위험: drop_attempt_bonus가 50이면 truncation_penalty(-30) 대비 마진 80.
        per-step 보상 누적이 이를 초과하면 drop 회피 가능성.

--- 방안 B: bonus만 축소 (보수적) ---

  drop_attempt_bonus : 150 → 80
  k2_precision       : 0.3 (유지)
  w_drop_base        : 100 (유지)

  거리별 보상 (방안 B):
    15m → 81     10m → 85     5m → 102    1m → 154    0.5m → 166

  장점: 기존 학습 안정성 유지, precision 비중만 소폭 상승
  위험: 여전히 10m→5m 차이가 17 — 충분하지 않을 수 있음

--- 방안 C: k2만 조정 (실험적) ---

  drop_attempt_bonus : 150 (유지)
  k2_precision       : 0.3 → 1.0
  w_drop_base        : 100 (유지)

  거리별 보상 (방안 C):
    15m → 150    10m → 150    5m → 151    1m → 187    0.5m → 211

  장점: 1m 이내 기울기 강화
  위험: 5m 이상에서 완전히 flat — 현재 10~15m 수준에서 개선 동기 없음

--- 방안 D: w_drop_base만 대폭 상향 ---

  drop_attempt_bonus : 150 (유지)
  k2_precision       : 0.3 (유지)
  w_drop_base        : 100 → 500

  거리별 보상 (방안 D):
    15m → 156    10m → 175    5m → 261    1m → 520    0.5m → 581

  장점: 기존 구조 유지하며 precision 신호 절대값만 증폭
  위험: 0m 부근 보상이 매우 커서 critic 불안정 가능성
