# exp_038 — 게이트 인지 학습 1단계: 평활 항이 EMA를 대체한다 (통과)

> **한 줄.** GRU 손실에 연속 프레임 예측 변화 벌점 $\lambda\sum_t\|\hat\delta_t-\hat\delta_{t-1}\|^2$를 더해 학습하면(정상 바람 데이터, 300 epoch),
> **EMA 없이** 주입해도 현재 방법(GRU-S + EMA 0.3)과 동률이다. Rule 38(첫 교차 게이트의 요동 편향)의 원인 처치이며, 손으로 고른 EMA α가 사라진다.

관련: [[research/release_gate_jitter]] (Rule 38) · [[experiments/exp_034_learned_temporal_filter]] · [[research/paper_outline_v6]] · [[experiments/training_history]]

## 1. 설정
`_fit_sl_seq.py --smooth λ` (λ ∈ {5, 20, 50}), v2 정상 덤프(s1a·s1b), MSE + λ·(부착 연속 프레임의 예측 변화²), 300 epoch. 주입 `--sl_ema 1.0`(EMA 없음).

## 2. 오프라인
| λ | $R^2$ 부착 | $R^2$ 릴리즈 | 예측 스텝 변화 |
|---|---|---|---|
| 0 (GRU-S) | 0.639 | 0.822 | 0.083 m/step |
| 5 | 0.640 | 0.839 | 0.046 |
| 20 | 0.578 | 0.814 | 0.029 |
| 50 | 0.516 | 0.778 | 0.020 (참 드리프트 0.018) |

## 3. 주입 (n=600, CEP50 / CEP90 / succ@0.5)
| 조건 | GRU-S + EMA 0.3 (현재) | GRU-S, EMA 없음 (seed 3000만) | λ=5, EMA 없음 | λ=20, EMA 없음 | λ=50, EMA 없음 |
|---|---|---|---|---|---|
| 정상 | 0.204 / 0.403 / 90.8 | 0.247 / 0.751 / — | 0.204 / 0.442 / 89.0 | 0.207 / 0.406 / 91.0 | 0.205 / 0.409 / 91.0 |
| 현실 A | 0.201 / 0.408 / 90.8 | — | 0.202 / 0.423 / 88.3 | 0.204 / 0.407 / 89.8 | 0.208 / 0.402 / 90.5 |
| 현실 B | 0.219 / 0.420 / 88.3 | — | 0.216 / 0.448 / 86.8 | 0.215 / 0.428 / 89.0 | **0.204 / 0.415 / 89.7** |

EMA를 빼면 GRU-S는 무너지고(CEP90 두 배), λ ≥ 20이면 EMA 없이 현재 방법과 동률(전부 ±0.02 m 잡음 범위). λ=50이 현실 B에서 가장 좋고 $R^2$는 가장 낮다 — 게이트 앞에서는 정확도보다 매끄러움이 먼저라는 Rule 38의 재확인.

## 4. 판정
**통과.** EMA(사후 처리, α=0.3)를 학습 목표 안의 항 하나로 대체. 다음: 3단계 — 게이트를 통과한 착지 오차를 직접 최적화(soft 첫 교차).
