# exp_055 — 새 플랜트 기준선(T0·T2) 재평가, 미학습 DR 2.0·2.5, 크기를 맞춘 GRU, EMA 없는 현실 돌풍 B

> **한 줄.** 새 플랜트에서 L0 + GRU-S는 DR 0.5 이상 모든 조건에서 T0·T2보다 CEP50·배달률·배달 시간이 전부 좋다(DR 1.0: 0.253 m 대 T2 0.401 m, −37%). 미학습 세기 DR 2.0·2.5에서도 잔차 이득이 유지된다(−36% / −29%). GRU의 크기·학습량을 손 설계 특징 MLP와 맞춰도 0.248 m로 그대로여서, **손 설계 특징(0.222 m)의 우위는 용량 차이가 아니다.** EMA는 현실 돌풍 B에서도 효과가 없다(0.290 대 0.289 m).

## 설정
- 플랜트·과제는 [[experiments/exp_052_grus_s2r_miss_label_3seed]]와 같다(PX4 PID, F450 1.7955 kg, 투하 하한 5 m, 바람 U[0,6] + Dryden).
- 기준선 = `baseline_drop.py` 스크립트 팔. T0 `--arm hover`(표적 위 정지 후 투하), T2 `--arm argmin`(등속 통과 + 투하 시점 재평가 규칙).
- 평가 seed 3000/4000/5000 × 200 쌍 평가. 기준선은 칸당 600 ep, L0·GRU는 L0 seed 1·2·4 합산 1800 ep.
- 실행 `isaac_lab/_b9_chain.sh`(컨테이너 안 `docker exec -d`), 240회 평가 실패 0. JSON `/tmp/base9/eval/`, 조정 `/tmp/base9/tune/`, 적합 `/tmp/base9/fit/`.
- L0·GRU의 DR 0–1.5·26–30 m는 `/tmp/grus8/pool/` 재사용.

## T2와 AeroThrow(arXiv 2507.13903) 대조
| 항목 | AeroThrow Algorithm 1 | 본 T2 |
|---|---|---|
| 투하 규칙 | 예측 구간에서 착지 오차 최소 시점 k*, k* = 첫 스텝이면 투하 | 같음 (`errs.argmin == 0`) |
| 미래 상태 | NMPC 예측 궤적 | 현재 속도 등속 외삽 |
| 탄도 모델 | 수평력 없음(항력·바람 없음) | 항력 + 명목 투하 지연 포함(더 강함) |
| 허용 게이트 | 없음 | 오차 ≤ 1.5 m일 때만 투하 |
| 궤적 | 계획기(창 τ를 키우면 속도 감소) | 통과 속도를 직접 조정 |
| 기체 | 쿼드로터 + 델타 팔 + 전자석 | 쿼드로터 + 투하 장치 |

→ 투하 시점 규칙은 같고 나머지는 다르므로 논문에서는 "AeroThrow식 투하 시점 규칙"으로 쓴다. 원문 인용은 "창 파라미터 τ를 키우면 비행 속도가 줄어든다"로 한정한다.

## 해석
- 이전 플랜트에서는 T2(0.282 m)가 L0(0.305 m)보다 CEP50이 좋았다. 새 플랜트에서는 DR 0.5 이상에서 L0가 T2보다 좋다. L0가 바람 편류를 일부 스스로 보정하게 된 것([[experiments/exp_051_grus_s2r_gain05_3seed_quick]], k ≈ 0.3–0.45)과 방향이 맞는다(인과는 분리하지 않음).
- 바람이 없으면(DR 0) T2 1.5 m/s(0.184 m)와 본 방법(0.182 m)이 같다. 규칙 기준선의 약점은 바람이며, DR 2.0 이상에서는 T2가 T0보다도 나쁘다.
- T2는 속도를 올리면 무너진다(2.5 m/s 0.746 m). 정확도를 얻으려면 1.0–1.5 m/s로 낮춰야 하고 배달 시간이 1.0–2.4 s 길어진다.
- 손 설계 특징의 우위(0.222 대 0.248–0.253 m)는 용량·학습량을 맞춰도 남는다.
- 새 플랜트에서 EMA는 기본 조건과 현실 돌풍 B 모두에서 효과가 없다 → 방법에서 빼도 수치가 바뀌지 않는다.

## 한계
- 기준선 투하 고도 5.3 m 대 L0 6.07 m — 기준선에 유리한 조건이다.
- 기준선 배달률 91–93%(시간 초과·자세 종료)는 스크립트 비행기의 한계로, 조정하지 않았다.
- T2의 속도 열화 원인(표적이 7 m에서 늦게 드러남 + 스크립트의 횡방향 보정 약함으로 추정)은 확인하지 않았다.
- 기준선은 스크립트 1개(L0 seed 없음)라 600 ep, 학습 팔은 1800 ep. 신뢰구간 없음.
- GRU 128은 조기 종료 없이 300 epoch 고정. 조기 종료를 쓰면 조금 나아질 수 있으나 검증 seed로 고르는 절차가 추가된다.
