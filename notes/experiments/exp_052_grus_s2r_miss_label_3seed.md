# exp_052 — 새 플랜트 L0 + GRU-S 본 검증: 정답 = L0가 남긴 실제 착지 오차, 3 seed × 전체 격자

> **한 줄.** 잔차 정답을 "바람 표류 계산값"에서 **"L0 단독 비행의 실제 착지점 − 참 표적"**으로 바꾸면 주입 계수 없이 3 seed 모두 개선된다. DR 1.0 합산 1800 ep: **CEP50 0.345 → 0.253 m(−27%), CEP90 0.897 → 0.546 m(−39%), succ@0.5 66.4 → 84.6%**, 배달률·배달 시간 불변. 고정 계수 0.5([[experiments/exp_051_grus_s2r_gain05_3seed_quick]], 0.284 m)와 바람만 아는 오라클 ×0.5(0.257 m)보다 좋다.

## 정답 정의
- 기존(`--label instant`): 매 스텝 "지금 투하하면" 무풍 탄도 예측 착탄점과 참 바람 적분 착탄점의 차이(`oracle_impact_residual(wind_only=True)`). 표적·L0 행동과 무관 → L0가 표류 일부(32–45%)를 스스로 보정하면 과보정([[experiments/exp_050_grus_s2r_dryrun_l0_self_compensation]]).
- 신규(`--label miss`): L0 단독(`--no_residual`) 에피소드의 실제 착지점 − 참 표적, 에피소드 내 상수. 착지하지 않은 에피소드는 제외. 부호는 기존과 같다(주입 = CCIP + 잔차).
- 구현: 환경 `_last_miss_xy`·`_miss_count`(착지 시 기록, reset 안 함) → `play.py --dump_sl`의 `miss`·`miss_n` → `_fit_sl_seq.py --label miss`. 착지와 reset이 같은 스텝이라 다음 프레임에서 읽는다.
- 확인(seed 1, 300 ep): 정답 크기 중앙값 0.322 m = L0 CEP50 0.321 m, "투하 시 조준 오차 + 표류"와 상관 0.90.

## 설정
- `ROOT=/tmp/grus8 LABEL=miss ORC=0 bash _grus_s2r.sh s1=… s2=… s4=…`. L0: seed 1·2 = exp_049 `model_1000.pt`, seed 4 = `/tmp/l0_s2r7b/…/model_final.pt`(1000 iteration).
- 덤프: 수집 시드 1000/2000 × 1500 ep, DR 1.0. GRU 26→64→2, 150 epoch, EMA 0.3, 주입 계수 없음.
- 평가 시드 3000/4000/5000 × 200, L0와 쌍. JSON `/tmp/grus8/s{1,2,4}/eval/`, 합산 링크 `/tmp/grus8/pool/`.
- 적합 R²(투하 시점): 0.615 / 0.684 / 0.707 — 실제 오차에는 투하 지연·낙하 계수 편차 등 예측 불가능한 성분이 있어 기존 정답(0.94)보다 낮다.

## 해석
- 15개 (seed × 조건) 전부 개선, 악화 없음. 무풍에서도 손해가 없다(−3%).
- **GRU를 붙이면 L0 seed 편차가 사라진다**: DR 1.0 CEP50 0.320–0.368 m → 0.247–0.257 m. 정답이 L0별 자체 보정 비율과 조준 편향을 흡수하기 때문이다.
- 바람만 아는 오라클 ×0.5보다 좋은 것은 새 정답이 바람 외에 L0의 체계적 조준 편향까지 담기 때문으로 보인다(직접 분해는 하지 않음).
- 학습 범위 밖(DR 1.5, 26–30 m)으로도 이득이 유지·확대된다.
- 닫힌 루프에서 관측 분포가 달라지는 문제는 나타나지 않았다.
- 실기 대응: 정답이 "던진 뒤 실측한 착지 오차"이므로 실기 데이터로 같은 방식의 재적합이 가능하다.

## 한계
- 이전 P 제어 L0의 L0 + GRU(0.204 / 0.403 m, 90.8%, 투하 3.4 m)보다 절대값은 나쁘다 — 투하 고도 6 m의 결과.
- 돌풍 A/B 조건, EMA α 재확인, 기존 기준선(T 팔)과의 비교는 새 플랜트에서 아직 하지 않았다.
