# exp_039 — 게이트 인지 학습 2·3단계: 게이트를 손실에 결합해도 평활 항 이상은 없다

> **한 줄.** (3단계) soft 첫 교차 게이트를 통과한 착지 오차를 직접 최적화하면 **오히려 나빠진다** — 그래디언트가 잔차의 정확도가 아니라
> "어느 프레임에서 놓을지"만 움직여 예측을 왜곡한다(릴리즈 프레임 $R^2$ 0.814 → 0.673 → −0.148). (2단계) 게이트가 발사할 프레임에
> 정확도 가중을 주는 형태는 닫힌 루프에서 CEP50 −0.002~−0.015 m로 방향은 일관되나 유의하지 않다(95% CI가 0 포함).
> **결론: 비행이 고정된 기록 위에서는 "매 프레임 정확 + 매끄러움"이 이미 게이트 최적해다.** 방법 수준 기여는 1단계(평활 항 = EMA 대체)로 확정.

관련: [[experiments/exp_038_gate_aware_stage1]] · [[research/release_gate_jitter]] (Rule 38) · [[research/paper_outline_v6]] · [[experiments/training_history]]

## 1. 정의
- 오프라인 게이트: 덤프의 공식 예측 오차 $e_t$(관측 ch 2–3 × 10 m)와 정답 드리프트 $\delta_t$로, 보정 예측 $c_t = e_t + \hat\delta_t$가 표적에 가장 가까운 프레임 $t^*$에서의 실제 착지 오차 $|e_{t^*} + \delta_{t^*}|$.
- 3단계 손실 `--gate γ --gate_beta β`: $t^*$를 softmin(β)으로 부드럽게 하여 $\sum_t w_t(\hat\delta)\,|e_t+\delta_t|^2$. 그래디언트는 $w_t$를 통해서만 흐른다.
- 2단계 손실 `--gate_weight W`: 참 보정 궤적 $|e_t+\delta_t|$의 softmin 가중(고정)으로 MSE를 가중 — 게이트를 미분하지 않음.
- 모두 정상 데이터, 평활 λ=20 위에, 300 epoch.

|---|---|---|---|---|

## 4. 해석
잔차가 게이트를 통해 착지에 미치는 유일한 지렛대는 **놓는 시점**이고, 시점을 옳게 고르는 최선의 방법은 매 프레임 드리프트를 맞히고
흔들리지 않는 것이다. 게이트를 손실에 넣으면 정확도와 무관한 방향(시점 이동)으로 예측을 밀어 오히려 해가 된다. 비행 정책의 조향 반응은
오프라인 기록에 없으므로 닫힌 루프로 확인했고, 결과는 같았다.

## 5. 결론 — 방법 수준 기여의 최종 형태
**"게이트 일관 잔차 학습" = 결과 공간 지도 잔차 + 시간 일관성 손실.** 사후 EMA를 손실 항 하나로 대체하며(1단계), 게이트 자체를 손실에
결합하는 것은 이득이 없다는 음성 결과를 근거로 붙인다. 본 방법의 최종 구성: GRU(관측 26 → 64 → 2), MSE + λ=20 시간 일관성, 정상 바람 데이터,
EMA 없음. 다음 = 표·그림을 이 구성으로 재생성 후 sim2real.
