# exp_036 — 불확실성 헤드: 평균+분산을 배우고 분산에 반비례해 물러선다 → **τ ≥ 1 전 구간에서 학습 팔 최고, τ=10은 오라클+EMA 수준**

> $\sigma_0^2/(\sigma_0^2+\sigma^2)$로 수축했다($\sigma_0$ = 0.3 m). 같은 데이터·라벨의 GRU-R보다 **모든 τ에서 좋고**,

## 4. 판정

| 기준 | 결과 |
|---|---|
| ① 정상 손실 없음 | ✅ 0.210 (gi 0.209), CEP90 0.411·succ@0.5 90.3%로 GRU-R의 꼬리 손실이 복구됨 |
| ② τ 3~10 회복 | **τ=10 ✅ −13.1%**, 학습 팔 최고이고 오라클+EMA(−14.1%)와 1 pp 차. succ@1.0 94.2%는 오라클보다 높음. τ=3 +4.8% — L0보다 나쁘지만 GRU-R보다 개선 |
| ③ τ ≤ 1 무해 | ✗ +9.0% / +18.5%. 다만 GRU-R(+17 / +24)의 절반 수준이고 τ=1은 gi와 동률 |

**분산 헤드는 같은 데이터·라벨의 GRU-R을 전 τ에서 이긴다** — 수축이 "모르면 덜 건드린다"로 작동한 증거. 그러나 분산의
τ 식별력이 19%뿐이라 물러서는 정도가 부족하고, τ ≤ 3의 손해가 0이 되지는 않았다.

## 5. 남은 손해의 원인과 후보

1. **수축이 절대 분산 기준이라 정상 바람에서도 30%를 깎고 τ=1에서는 38%밖에 안 깎는다.** 상대 기준(정상 바람 기준 σ 대비 초과분)으로
   바꾸면 정상 이득을 보존하면서 τ가 짧을 때 더 세게 물러설 수 있다 — 재학습 없이 내보내기 수식만 바꾸면 되는 실험.
2. **관측 이력 2~5초로 τ를 구분하는 정보 자체가 19%뿐이다.** 이것이 실제 상한이면 τ ≤ 1의 손해 일부는 남는다 — Rule 42의 원리적 한계.

## 6. 결론

시변 바람에서 쓸 단일 모델은 **GRU-U**다: 정상 바람에서 수제 gi와 동등, τ=10에서 오라클 수준, τ=1에서 gi와 동등, 그 사이 전부 GRU-R보다 낫다.
논문 표에는 GRU-S(정상, 0.204)와 GRU-U(시변) 두 행이 자연스럽고, "잔차의 이득은 상관 시간에 비례하며 상관이 짧을수록 스스로 물러선다"는
문장은 τ=10 → 1의 단조 감소(−13 → +9%)와 GRU-R 대비 개선으로 뒷받침된다. 완전한 무해(L0 동률)는 미달이며 그대로 적는다.
