# exp_034 — 누적 특징을 학습된 시간 필터(GRU)로 대체: 정상 바람에서 같은가(✅), 시변 바람에서 나은가(⛔ 라벨이 병목)

> **한 줄.** L1-SL의 손 설계 부분(tilt 누적 10 + gi 2)을 원 관측 26채널 위의 GRU(hidden 64)로 바꾼다.
> 물음은 둘: ① 정상 바람에서 수제 누적과 같은 성능이 나오는가(같아야 대체 가능), ② τ 혼합 데이터로 학습하면
> OU 바람(τ = 10·3·1 s)에서 수제 누적이 잃는 이득을 되찾는가. 참조 상한은 오라클+EMA(τ ≤ 3에서 그것도 진다 — Rule 42).

## 2. 판정 (사전 등록)

- ① 정상: GRU-S CEP50이 L1-SL gi(0.209, n=600)와 ±0.01 이내면 "대체 가능". CEP90·succ@0.5도 함께(Rule 40).
- ② OU: GRU-M이 τ = 10·3에서 L0(0.272·0.282)보다 낫고 gi(0.263·0.292)보다 나으면 "시변 바람 회복". τ ≤ 1은 오라클도 지므로 기대하지 않는다.
- MLP38-M이 GRU-M과 같으면 이득은 **데이터(τ 혼합)** 때문이고, GRU-M만 나으면 **모델(학습된 창)** 때문이다.

**판정 ① 통과.** 손 설계 누적 12채널 없이, 원 관측 26채널 위의 GRU가 정상 바람에서 동등 이상(CEP50 −33.3% vs −31.6%,

(τ=1: +13.2% vs +9.8%). 이것이 ②의 출발점 — 혼합 학습판(GRU-M)이 답한다.

### 3.4 혼합 학습판 — 순간 바람 라벨로 OU 데이터를 배우면 **더 나빠진다** (n=600, CEP50 / CEP90 / succ@0.5)

| 3 | 0.282 / 0.569 / 79.8 | **0.292 / 0.583 / 78.5** | 0.307 / 0.803 / 73.5 | 0.298 / 0.601 / 77.5 | 0.313 / 0.743 / 74.0 | 0.299 / 1.092 / 65.8 |

| 0.3 | 0.280 / 0.555 / 80.5 | **0.310 / 0.600 / 80.2** | 0.362 / 0.930 / 65.2 | 0.319 / 0.616 / 73.7 | 0.377 / 0.982 / 62.2 | 0.538 / 1.318 / 44.5 |

세 가지가 보인다.

1. **판정 ② 실패, 그리고 방향이 반대다.** OU 데이터를 섞어 학습한 두 팔(GRU-M·MLP38-M)은 τ ≤ 3에서 정상 데이터만 배운
   팔보다 **더** 진다(τ=1: gi +9.8% → MLP38-M +20.2%, GRU-S +13.2% → GRU-M +29.1%). 모델을 바꿔도, 데이터를 늘려도 같다.
2. **왜 — 라벨이 가르치는 것이 "순간 바람 추종"이기 때문이다.** 라벨은 "릴리즈 순간의 바람을 고정하고 적분한 드리프트"다.
   OU 데이터로 배우면 회귀기는 순간 바람을 더 빨리 따라가도록 바뀐다. 그런데 실제 착지는 **낙하 0.85 s 동안의 바람 적분**이고,
   τ ≤ 3에서는 순간 바람이 그 적분의 나쁜 예측치다 — 참 순간 바람을 받는 오라클+EMA가 가장 크게 지는 이유(τ=1: +40%).
   순간 추종을 잘 배울수록 **오라클의 실패 방식에 수렴**한다. 정상 데이터만 배운 팔은 "전 구간 평균"을 내므로 우연히
   보수적이고, 그래서 덜 진다.
3. **정상 바람에서도 혼합 학습은 꼬리를 해친다.** GRU-M CEP90 0.454(GRU-S 0.403), MLP38-M 0.512(gi 0.411).
   예측 스텝 변화 0.083 → 0.125 m/step — 추종이 빨라지면 요동도 커진다(Rule 38).

## 4. 결론

- **GRU 시간 필터는 수제 누적 특징을 대체한다** (원 관측 26 → 정상 바람 CEP50 0.204, gi 0.209). 손 설계 12채널은 더 이상 필요 없다.
- **시변 바람의 병목은 모델도 데이터도 아니고 라벨이다.** 순간 바람 라벨은 τ가 짧을수록 착지와 무관한 목표가 된다.
  MSE의 최적해가 $E[\text{착지 드리프트} \mid \text{이력}]$ 가 되려면 라벨 자체가 **실현된 착지 드리프트**(낙하 구간의 실제 바람으로
  적분한 값, 곧 실기의 "예측 vs 실측")여야 한다. 그러면 τ가 짧을 때 예측이 자동으로 평균 쪽으로 수축하고, 학습된 필터의 창도
  "무엇을 예측해야 하는가"에 맞춰 정해진다. → **exp_035: 실현 라벨.** 덤프에 원 상태(pos·vel·alt)를 추가하고, 프레임 t의 라벨을
  기록된 **미래 바람열**로 적분해 만든다(반사실 실현 드리프트 — 모든 프레임에 라벨이 생긴다).
- 부수: 혼합 학습판의 τ=10 CEP50(0.252)이 gi(0.263)보다 나은 것은 유일한 이득이며, 실현 라벨에서는 이 구간이 더 열릴 것으로 본다.
