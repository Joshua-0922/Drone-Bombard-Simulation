# exp_044 — F450 단일 모터 스텝 응답: 가속 τ ≈ 80 ms, 감속 τ ≈ 65–95 ms (Gazebo 기본값보다 3–6배 느림)

> **한 줄.** 프롭을 한 모터에만 달고 PX4 액추에이터 테스트로 30 % ↔ 50 % 스텝을 8회씩 주며 노트북 마이크로 녹음했다.
> 소리의 대역 에너지를 회전수로 환산해 "지연 + 1차 지연"을 맞춘 결과, 가속 시정수 약 80 ms, 감속 약 65–95 ms였다.
> Gazebo `x500_drop`의 PX4 기본값(12.5 / 25 ms)보다 확실히 느려서 0.08 / 0.08 s로 바꿨다. 모터 2(CCW)와 3(CW)은 측정 정밀도 안에서 같다.

관련: [[research/f450_motor_dynamics]] · [[research/sim2real_field_feasibility_f450]] · [[research/sim2real_hardware_spec]] · [[experiments/exp_043_gazebo_px4_sim2sim]] · [[experiments/training_history]]

## 1. 설정
| 항목 | 값 |
|---|---|
| 기체 | F450, Polytronics 2212 920KV, DJI 9450 프롭, Polytronics MR X-3 OPTO 30 A(PWM, BEC 없음), Vega 4S 5200 mAh(15.44–15.45 V) |
| FC | Pixhawk 6C mini, PX4 v1.16.2, `PWM_MAIN_MIN/MAX` 1100/1900 µs, 비무장 |
| 명령 | `MAV_CMD_ACTUATOR_TEST`, param5 = 모터 번호(1..), 값 0.30 ↔ 0.50 = PWM 1340 ↔ 1500 µs, 1.5 s 유지, 8회 |
| 기록 | `SERVO_OUTPUT_RAW` 200 Hz 요청(실측 간격 4.5 ms), 노트북 마이크 48 kHz(WASAPI 배타 모드), 모두 호스트 시계 |
| 시험 | 3차 = 모터 2(CCW), 4차 = 모터 3(CW). 1·2차는 아래 §4 이유로 제외 |
| 코드·데이터 | `hardware/bench/motor_step/` (`motor_step.py`, `analyze_motor_step.py`, `data/run3_motor2_*`, `data/run4_motor3_*`) |

## 2. 결과
| 항목 | 모터 2 (CCW) | 모터 3 (CW) |
|---|---|---|
| 명령 → PWM 출력 (중앙값) | 5.5 ms (−0.3–12.1) | 5.5 ms (0.8–9.4) |
| 정상 회전수 30 % / 50 % (2날 기준) | 4,270 / 5,863 rpm | 4,282 / 5,869 rpm |
| 가속 데드타임 / τ (90 % 구간) | 8 ms (−30–44) / **80 ms (40–115)** | 0 ms (−18–30) / **80 ms (40–115)** |
| 가속 50 % / 90 % 도달 | 46 / 127 ms | 61 / 132 ms |
| 감속 데드타임 / τ (90 % 구간) | 44 ms (24–93) / **95 ms (60–138)** | 36 ms (−2–80) / **65 ms (5–105)** |
| 감속 50 % / 90 % 도달 | 108 / 216 ms | 51 / 92 ms |
| 적합 RMSE (정규화) | 0.14 / 0.15 | 0.20 / 0.17 |

- 정상 회전수 차이는 0.3 % 이내, 가속 τ는 같다. 감속 τ 차이는 구간이 겹쳐 실제 차이로 보지 않는다.
- 데드타임에는 Windows 오디오 입력 지연 보정 오차(약 ±20 ms)가 더해진다. τ는 이 오차와 무관하다.
- 두 시험 모두 진행 중 회전수가 약 1 % 내려갔다(배터리 전압 하강으로 추정).

## 3. 조치
- `gazebo_models/x500_drop/model.sdf`: `timeConstantUp/Down` 0.0125 / 0.025 → **0.08 / 0.08 s**(4개 로터). exp_043 결과는 이전 값 기준이므로, 다음 Gazebo 평가 때 새 값으로 다시 돌린다.
- **DR 설계와의 차이:** [[research/sim2real_hardware_f450]] §0의 모터 τ 사전값은 0.04 s, DR U[0.02, 0.06] s다(선정 추진계 AIR2216 II + T1045 + DShot 기준). 이번 측정은 현재 장착된 2212 920KV + 9450 + PWM ESC로 τ ≈ 0.08 s라 그 범위 밖이다. → **10-25 현재 추진계 유지로 결정, §0.3 τ 사전을 0.08(1 + 0.5 s ξ) = U[0.04, 0.12] s로 변경.** T/W 공칭도 2.8 → 2.3.
- Isaac에는 모터 모델이 없다(10 Hz 속도 명령 + EMA). 모터 지연은 비행 로그의 PX4 속도 스텝 응답 동정(P0)에 함께 담긴다.

## 4. 측정 과정에서 생긴 문제
| 문제 | 해결 |
|---|---|
| 액추에이터 테스트에 ACK가 오지 않고 모터도 안 돎 | PX4 Commander는 param5 1..을 Motor1..로 매핑한다. 출력 함수 번호(102)를 보내면 범위 밖 → 2로 수정 |
| 1차: 모터 소리가 처음 약 3 s 뒤 사라짐 | Windows 마이크 배열의 잡음 억제가 일정한 모터 음을 지움(1 kHz 테스트음도 0.5 s 만에 사라짐). WASAPI 배타 모드로 우회 |
| 2차: 신호 약함, 짧은 창 음높이 추적 실패 | 노트북을 가까이, 반복 4 → 8회, 음높이 대신 대역 에너지를 스텝 평균해 회전수로 환산 |
| SD 로그에 남지 않음 | `SDLOG_MODE` 0(무장 중만 기록). 액추에이터 테스트는 비무장이라 MAVLink로 기록 |

## 5. 한계와 다음
- 회전수를 직접 잰 것이 아니라 소리 크기 ∝ rpm^k(k ≈ 2.5–2.8)로 환산했다. τ 신뢰구간이 넓다(약 ±40 ms).
- 정밀값이 필요하면 광학 회전수 센서(반사 테이프 + IR + 아두이노) 또는 회전수 피드백이 있는 DShot ESC로 다시 잰다.
- 모터 1·4는 미측정(같은 부품이라 비슷할 것으로 추정).
