# exp_037 — 상대 분산 수축 + 현실 바람(평균풍 + 돌풍) 평가 → **현실 돌풍에서는 모든 학습 팔이 이득을 유지하고, 정상 학습판 GRU-S가 최고**

> **한 줄.** ① 상대 분산 수축(정상 바람 기준 σ 대비 초과분만 물러섬, p=2·4)은 정상 바람과 현실 돌풍에서 절대 수축의 30% 손실을 되찾지만
> 가혹 조건(돌풍만, τ ≤ 3)에서는 오히려 덜 물러서 손해가 커진다 — 분산의 τ 식별력(19%)이 근본 한계.
> ② 새로 만든 **현실 바람 모드**(비행마다 다른 평균풍 + Dryden형 OU 돌풍 20~30%, τ 10·3 s)에서는 **모든 학습 팔이 정상 바람의
> 이득을 거의 그대로 유지**한다: GRU-S −33% / −28%, 오라클 −36% / −35%. 앞선 τ 사다리의 τ ≤ 3 손해는 평균풍 없이 돌풍만 둔
> 스트레스 시험의 결과였다.

## 2. 상대 수축 — τ 사다리 (ΔCEP50 vs L0; CEP50 / CEP90 / succ@0.5)

| τ | GRU-S | GRU-U 절대 | GRU-U rel p2 | GRU-U rel p4 |
|---|---|---|---|---|
| ∞ | −33.3% (0.204 / 0.403 / 90.8) | −31.2% (0.210 / 0.411 / 90.3) | −32.2% (0.207 / 0.417 / 89.7) | −32.9% (0.205 / 0.411 / 90.3) |
| 10 s | −5.5% | **−13.1%** | −7.4% | −9.6% |
| 3 s | +5.7% | **+4.8%** | +6.2% | +8.9% |
| 1 s | +13.2% | **+9.0%** | +13.6% | +13.6% |
| 0.3 s | +14.0% | +18.5% | +26.4% | +26.3% |

상대 수축은 정상 바람의 손실을 되찾지만(0.205~0.207) 가혹 조건에서 절대 수축보다 나쁘다. **절대 수축이 τ ≤ 3에서 낫던 것은
τ를 식별해서가 아니라 전체를 30% 깎은 효과였다** — 분산의 τ 식별력(σ 0.197 → 0.234, 19%)은 상대 기준으로 쓰기엔 너무 약하다.

## 3. ⭐ 현실 바람 — 평균풍 + 돌풍 (n=600, CEP50 / CEP90 / succ@0.5, 괄호 ΔCEP50)

| 팔 | A: 20% 돌풍, τ=10 | B: 30% 돌풍, τ=3 |
|---|---|---|
| L0 | 0.301 / 0.578 / 77.8 | 0.305 / 0.593 / 77.0 |
| gi (수제 누적) | 0.213 / 0.435 / 90.3 (−29.2%) | 0.218 / 0.432 / 89.3 (−28.5%) |
| **GRU-S (정상 학습)** | **0.201 / 0.408 / 90.8 (−33.2%)** | 0.219 / 0.420 / 88.3 (−28.0%) |
| GRU-R (실현 라벨) | 0.217 / 0.452 / 88.3 (−27.9%) | 0.227 / 0.486 / 85.8 (−25.5%) |
| GRU-U 절대 | 0.213 / 0.418 / 89.7 (−29.3%) | 0.221 / 0.449 / 88.2 (−27.6%) |
| GRU-U rel p2 | 0.200 / 0.416 / 90.7 (−33.6%) | **0.208 / 0.444 / 88.0 (−31.8%)** |
| GRU-U rel p4 | 0.202 / 0.415 / 90.7 | 0.214 / 0.446 / 88.0 |
| 오라클+EMA | 0.194 / 0.388 / 91.5 (−35.5%) | 0.198 / 0.420 / 90.3 (−35.1%) |

**현실적인 돌풍에서는 이득이 유지된다.** 돌풍이 평균풍의 20~30%면 회귀기가 평균풍을 잡는 것만으로 충분하고, τ=3의 돌풍도
착지를 크게 흔들지 않는다(L0 자체가 거의 안 변함: 0.301 → 0.305). τ 사다리의 τ ≤ 3 손해는 **돌풍 세기를 평균풍 수준으로 둔
스트레스 시험**의 결과였다.

## 4. 결론 — 논문에 어떻게 쓰나

1. **본 방법 = GRU-S** (RL 비행 + 관측 이력 위의 GRU 잔차, 정상 바람 데이터로 학습). 정상 바람 0.204, 현실 돌풍 A 0.201·B 0.219로
   전 조건에서 학습 팔 최고이거나 동률, 가장 단순하다. 실현 라벨·분산 헤드는 **현실 조건에서 필요 없다.**
2. **강건성 절**: (a) 현실 돌풍 A·B에서 이득 유지(표 3), (b) 돌풍만 두는 스트레스 사다리에서는 낙하 시간보다 짧은 상관에서 모든 팔이
   지고(오라클 포함), 절대 수축 GRU-U가 손해를 절반으로 줄인다 — "보조 변형"으로 한 문단.
3. **한계**: 스트레스 조건에서 완전 무해는 미달. 수직 돌풍·전단 미모델.
4. 상대 수축은 채택하지 않는다(현실 조건 +0.01 m 이득은 잡음 범위, 스트레스 조건 악화).
