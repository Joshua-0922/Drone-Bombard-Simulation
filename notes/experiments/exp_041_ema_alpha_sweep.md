# exp_041 — EMA α 민감도: 0.1~0.4 평탄, 0.5부터 악화, 무필터는 유의하게 나쁨 → α = 0.3 확정

> **한 줄.** 본 방법(L0 + GRU-S)의 EMA α를 {0.1, 0.15, 0.2, 0.3, 0.4, 0.5, 0.7, 1.0}으로 바꿔 정상 조건(DR 1.5, 3 seed × 200)에서 주입 평가했다.
> **α ≤ 0.4에서 CEP50 0.201~0.204로 평탄**, 0.5부터 꼬리(CEP90)와 성공률이 무너지기 시작해 무필터(α=1)는 0.239 / 0.775 / 76.0%로 유의하게 나쁘다(paired CI [+0.007, +0.053]).
> **α = 0.3 유지**: 평탄 구간 안에서 지연이 가장 짧은 값(시간 상수 0.28 s)이며, 표·그림 재생성이 필요 없다.

관련: [[research/release_gate_jitter]] (Rule 38) · [[experiments/exp_028_l1_sl_pilot]] · [[research/final_tables_v6]] · [[experiments/training_history]]

## 1. 설정
같은 GRU-S 가중치(`/tmp/sl/res_gru_S.pt`), `play.py --sl_ema α`만 변경. 스크립트 `isaac_lab/_ema_sweep.sh`, 산출물 `/tmp/ema/GRUS_ema{α}_s{seed}.json`(α=0.3은 `/tmp/gru/GRUS_E_tau0_s*`). 시간 상수 = −0.1 s / ln(1−α).

## 3. 해석
- α ≤ 0.4는 예측 요동이 정답 요동 수준(0.018 m/step) 아래로 눌려 게이트 편향이 사라진 구간. α=0.1(시간 상수 0.95 s, 낙하 시간보다 긺)도 정상 바람에서는 손해가 없다 — 바람이 일정하면 지연은 무해하기 때문.
- α ≥ 0.5부터 CEP90이 0.45 → 0.54 → 0.78로 꼬리부터 무너진다. 첫 교차 게이트가 요동의 극단값을 잡는 Rule 38의 형태 그대로다.
- 시변 바람(현실 B, τ=3 s)에서는 지연이 손해로 바뀌므로 평탄 구간의 **큰 쪽 끝**이 안전하다. 0.4는 succ@0.5가 88.5%로 첫 이탈 징후를 보이므로 **0.3**.

## 4. 결정
**α = 0.3 확정.** 논문 §4.4 한 문장: "α는 정상 조건 민감도 스윕(부록 표)에서 평탄 구간 [0.1, 0.4]의 지연이 가장 짧은 값으로 정했다. 필터를 빼면 CEP50 +17%, CEP90 +92%."
