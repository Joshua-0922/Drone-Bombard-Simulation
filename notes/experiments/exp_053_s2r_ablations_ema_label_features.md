## 해석
- **손 설계 특징 + MLP > GRU-S.** 3 seed 전부에서 CEP50·CEP90·succ@0.5 모두 앞선다. 이전 Table 5의 "동등, 손 설계 불필요"는 새 플랜트에서 성립하지 않는다. 단, 두 팔은 용량·학습도 다르다(MLP 128폭 2층·300 epoch·프레임별 손실 대 GRU 64·150 epoch). 원인 미분리.
- **EMA 무관.** 이전 "평활을 빼면 2배 악화"는 재현되지 않는다. 새 정답이 에피소드 내 상수라 GRU 출력이 이미 매끄럽기 때문으로 보인다(스텝 변화 약 0.05 m).
- **정답 정의.** 기존 정답 전량 주입은 합산에서 L0보다 나쁘다(seed 1 +46%). Rule 50의 직접 근거.
- **정답 수.** 100 → 300 → 1000 → 약 1950으로 단조 개선. 100개도 합산 −10%지만 seed 1에서는 손해(+5%). epoch을 150으로 고정해 N = 100은 갱신 150회뿐 — 데이터 양과 최적화 횟수가 분리되지 않았다.
- **이력.** 순간 관측만으로도 이득(−18%)이 있지만 GRU-S보다 12% 나쁘다. 이전(exp_028)처럼 L0보다 나빠지지는 않는다.
- **바람 오라클.** 전량은 과보정(seed 1에서 L0보다 나쁨), 0.5배는 본 방법과 동률 — 상한선으로 쓸 수 없다.

## 한계
- 쌍 유의성 검정·부트스트랩 구간 없음. 본 방법과 4% 이내 차이(EMA 스윕, 오라클 0.5)는 동률로 본다.
- 손 설계 팔의 R²(0.465 / 0.540 / 0.585)는 다른 분할·프레임 단위라 GRU의 R²(0.454 / 0.545 / 0.554)와 직접 비교할 수 없다.

## 결정 필요
- 본 방법을 GRU-S로 유지할지, 손 설계 누적 특징 + MLP로 바꿀지. 판단 전에 용량·epoch을 맞춘 비교(GRU 128·300 epoch, 또는 GRU에 누적 특징 입력)와 다른 조건(DR 0–1.5, 26–30 m, 돌풍)에서의 비교가 필요하다.
