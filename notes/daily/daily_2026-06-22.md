## 주요 결정 & 발견

- **핸드오프 윈도우의 진짜 레버 = 탐지 게이트, 고도 아님.** (→ [[research/detection_gate_vs_altitude]], Rule 13)
  - 고도↑는 마커 apparent size를 1/고도로 줄여 YOLO가 더 가까워야 lock → 탐지가 일찍이 아니라 동등/늦음.
  - `vision_callback`의 200 px 공간 필터가 고도 무관하게 핸드오프를 "거의 머리 위"로 클립.
  - 넓어진 FoV는 순항 시작에서 X-like 지면 false positive를 잡아 spurious CRUISE→TRACKING(conf=0.00) 유발.
- **dry-run 격리 원칙 준수:** `--checkpoint-dir rl_dryrun_alt10` + `WANDB_MODE=offline`로 메인 `sac_drop_preempt.zip` 보호 (06-17 clobber 인시던트 재발 방지).
- **conf 게이트 임계는 로그 데이터로:** real 마커 0.73–0.95 vs 지면 FP ≤0.45 → 0.50이 간격에 안착.
- 사용자가 직접 커밋 예정 → 변경분 **미커밋** 유지.
