- **크래시 원인 = Spot VM 선점(preemption)**
  - WandB state `crashed` (≠ `failed`) + `spot-vm` 태그 + 7시간 후 갑작스러운 종료

  - 코드 에러라면 `failed`로 기록되고 traceback이 남아야 함

- **학습은 실패 중 — hover exploit 발견**
  - 1,385 에피소드 중 **1,381개(99.7%)가 stagnation 종료** (step 201에서 매번)
  - `reached_close = 0`: 373K step 동안 목표 근처 도달 0회
  - `rew_dist ≈ 0`, `rew_orient = 0`: 드론이 목표를 향해 이동하지 않음
  - `rew_vision = 0.447`: YOLO는 마커를 보고 있지만, 드론은 제자리에서 vision 보상만 수집
  - `ent_coef = 5.03` (373K step에서도 높음): 정책이 수렴하지 못하고 있음 → replay buffer 오염 때문

- **replay buffer 오염 (rl_rules 위반)**
