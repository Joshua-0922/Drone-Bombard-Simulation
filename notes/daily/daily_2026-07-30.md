## 개선 방향 (근거 기반)

1. **리드(lead) 부재가 1차 병목** — obs에 타겟 속도가 없고 정책은 무기억(MLP) →
   CCIP가 **현재** 타겟 위치를 조준, 낙하시간(t_f≈1.2–1.5 s) 동안 타겟이 |v|·t_f
   (최대 2–3 m) 이동 = 구조적 miss. 착탄 med 0.78–1.06 m(≈E[|v|]·t_f 스케일)가 서명.
   개선 후보(우선순위순):
   - (a) **Singer-KF obs v19 포팅**(obs 28→35): 추정 타겟 속도/가속 제공 — CT/CA까지
     단일 필터로 커버(설계 의도). 단 fresh start 또는 입력층 zero-init 부분 로드 필요.
   - (b) 중간 단계: **privileged target-vel obs(2-dim)** 추가(obs 28→30) — KF 없이
     리드 학습 가능성 분리 검증(Stage A/B 분리 원칙, Rule 22 교훈).
   - (c) **lead-aware referee/보상**: base env Phase-3 `w_lead`(예측 착탄 vs 타겟
     예측 위치) 이식 — 보상 단독 개입은 Rule 22 주의(구조 개입과 병행).
2. **ca의 out_of_range 25%** — 가속 타겟 이탈을 못 쫓음(release도 63.5%로 하락).
   `target_accel` 커리큘럼(0.25→0.5) 또는 에피소드 내 |v| cap(현실적 타겟 속도 상한)
   부터. bad_attitude 8건은 공격적 추격 선회의 부산물로 추정.
3. **timeout 20–28%** — 접근은 하나 게이트가 안 열림(이동 타겟에서 d_impact≤1.5 m
   충족 확률 하락). release_radius 재검(1.5→2.0, v18 bootstrap 교훈) 또는 게이트
   조준을 리드 반영으로.
4. **iter 예산 확대는 2차** — exp_015 교훈(Rule 20f: 예산 확대 단독으론 명중 능력
   미형성). 구조 개입(1번) 후 재학습이 순서.
5. gm(GM/OU) 모션 baseline run — 4모델 비교 완성용.
