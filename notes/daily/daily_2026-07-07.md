## 1. 4-Layer 계층형 보상 (원설계, 2026-03)

$$R_{total} = R_1^{safety} + R_2^{stability} + R_3^{approach} + R_4^{drop}$$

- $R_1$: 저고도(−10)·과속(−8) 페널티 / $R_2$: $-w_{time} - w_\omega\|\omega\|^2 - w_{\Delta a}\|\Delta a\|^2$ / $R_3$: 거리+방향 / $R_4$: $w_{drop}\cdot e^{-k_2 d_{err}} + 100\cdot\mathbf{1}[d_{err}\le0.1]$

**장점:** 안전·안정·접근·투하를 분리해 ablation 가능한 구조. 종단 jackpot(+100)으로 명확한 성공 신호.
**단점 (치명):** 거리 보상에 지수 포텐셜 $e^{-k_1 d}$ 사용 — $k_1{=}1.0,\ d{=}45\mathrm{m}$이면 $e^{-45}\approx6.5\times10^{-20}$ = **machine zero → 원거리에서 학습 신호 전무**.
**변경:** 지수 포텐셜 → **선형 거리 보상** (아래 #2). 규칙화: $e^{-k_1 d_{max}} > 10^{-4}$ 필수 (50m 범위면 $k_1<0.18$) — [[research/rl_rules]] Rule 4.

## 2. 선형 거리 보상 (2026-03-20)

$$R_{3,dist} = w_{dist}\cdot(d_{prev} - d_{xy}), \quad w_{dist}: 10.0 \to 1.0$$

**장점:** 어떤 거리에서도 기울기 존재. potential-based라 순환 착취에 강함.
**단점:** 에피소드 전체 합산이 망원경처럼 접혀 총합이 작음 (핸드오프 1m → 성공까지 **단 +2.0**) → 종단 페널티(−20)와 비대칭해지면 쉽게 압도당함 (#5의 트랩 원인 중 하나).
**변경:** 이 자체는 유지. 종단 영역은 proximity 밀집 보상(#4)과 종료 구조(#5)로 보강.

## 3. Anti-Milking 패치 (2026-03-22)

- **방향 보상 speed gate:** $R_{3,orient} = w_{heading}\cdot\cos\theta\cdot\min(v_{xy}/2.0,\,1)$ — 호버 상태($v<0.1$)면 방향 보상 0
- $w_{time}$ 0.01→0.05 (5× 긴급성), truncation −50 (투하 없이 500스텝 종료 방지)

**장점:** "제자리서 카메라만 표적에 맞춰 500스텝 × $w_{heading}$ 젖 짜기(milking)" 해킹 차단. anti-quitting.
**단점:** 해킹의 사후 봉합이라 보상 지형 복잡도 증가. 이후 v9에서 방향 보상 자체가 0으로 제거되며 상당 부분 대체됨.
**교훈:** 정지 상태에서 이득이 누적되는 밀집 항은 반드시 속도/진행 게이트를 달 것.

## 4. v9 재설계 (2026-06-13): proximity + 종료 구조

- $w_{heading}\to0$, penalty_target_lost→0, **proximity 밀집 보너스 0.3**, success(0.5m, +100)·overshoot(−20) **종료**, max_steps 400→300

**장점:** 보상 항 단순화(방향 보상 제거로 milking 여지 원천 차단). 성공/overshoot 즉시 종료로 에피소드 낭비 감소.
**단점:** overshoot 종료(−20)가 이후 v12에서 **"해자(moat)" 트랩**이 됨(#5). 이진 성공 게이트(+100)는 게이트 밖에서 기울기 없음.

## 5. v13 종단 보상 교정 — Overshoot 해자 해체 (2026-06-16, [[research/terminal_overshoot_trap]], Rule 10)

**문제 (v12):** 정하방 카메라 전환으로 핸드오프가 d_xy≈1.0m에서 시작 → `overshoot_close_threshold=1.5` > 1.0이라 **overshoot 가드가 step 1부터 무장**, action 8m/s로는 0.5m 성공원 제동 불가 → 성공 +100 앞을 −20 해자가 둘러쌈 → 정책이 "표적 돌진 = 위험"을 학습, ~1.0m 호버 수렴 (ep_rew −20.5 고정, success 0회).

**변경 (config-only):**

| 파라미터 | v12 → v13 | 이유 |
|---------|-----------|------|
| overshoot_close_threshold | 1.5 → **0.6** | 핸드오프(~1m)에서 무장 방지 |
| overshoot_margin / penalty | 1.5→**2.0** / −20→**−10** | 여유↑, 지뢰 완화 |
| success_radius | 0.5 → **0.8** | 도달 가능한 게이트 → +100 최초 발생 |
| action_vx/vy_scale | 8/5 → **4/3** | 종단 제동력 확보 |
| w_proximity / proximity_radius | 0.3→**0.6** / 5.0→**2.0** | pull-in 기울기를 실작동 영역에 집중 |

**결과:** v13 clean 20-ep eval **80% (16/20)**, mean closest 0.81m — 본 연구 Gazebo 트랙 최고 성적.
**장점:** 종단 위험/보상 비대칭을 수치로 진단하고 config만으로 교정. **단점:** 성공원 0.8m 완화는 커리큘럼 부채(0.8→0.5 재조임 미완). 실패 4건 전부 종단 stagnation(0.81–1.09m) — 축소된 authority(4/3)의 trade-off.
**교훈 (Rule 10):** 종단 페널티 가드의 무장 반경은 **에피소드 시작 거리보다 안쪽**이어야 하고, 액추에이터 스케일은 성공원 크기와 정합해야 함.

## 6. v15 B+C 댐핑 — wobble 교정 (2026-07-01, [[experiments/exp_011_wobble_lpf_reward_damping]], Rule 15·16)

**문제:** eval deterministic인데도 wobble → 탐험 노이즈가 아닌 **학습된 bang-bang 정책** (PX4 수신 명령 jerk RMS 2.92 m/s/sample).

**변경:**
- **(B) 근접-게이팅 속도 댐핑:** $r_{3,vel} = -w_{vel}\cdot v_{xy}\cdot\max(0,\,1 - d_{xy}/r_{damp})$ — 원거리 0(순항 자유), 마커 근처만 감속 유도. $w_{vel}$ 0.15→0.08 완화, $r_{damp}$ 4.0→3.0
- **(C) smoothness 가중 상향:** $w_{ang}$ 0.05→0.15, $w_{\Delta a}$ 0.05→0.20 (전진 속도 무관, jerk만 억제)
- (로직) 컨트롤러 EMA LPF α=0.4 — 학습==배포 플랜트

**장점:** LPF A/B로 jerk RMS **−45%**, 평균 속력 불변(오히려 +13%) — 증상(로직)과 원인(보상 인센티브)을 분리 타격. 근접 게이팅으로 "너무 느리게 말고" 제약 충족.
**단점 (회귀 의심, 미확정):** `vel_damp_radius=3.0m` ≫ `success_radius=0.8m` — 댐핑 반경이 v14의 기존 실패 구간(final-approach stagnation 0.5–1.2m)을 정확히 덮어 **재타격**했을 가능성 (v15 310K "X마커 미도달" 관찰). GPU 드라이버 불일치(Rule 20)로 eval 차단 중이라 확정 불가.
**교훈 (Rule 16):** **속도/smoothness 댐핑 반경은 반드시 성공·종료 반경보다 작게.** 제안 변경: $r_{damp}$ 3.0→~1.0 또는 $w_{vel}\to0$ fallback.

## 8. Isaac exp_014 — slant-range conf 감쇠 (2026-07-05)

$$g = \mathrm{clamp}\bigl(1 - (slant - 5)\cdot0.1,\ 0.1,\ 1\bigr), \quad conf_{eff} = conf\cdot g$$

**장점:** 고도-farming 공짜 소득 제거 + 실 YOLO 거동과 parity. A2(감쇠 ON) R_alt=0.0000 vs A0′(OFF) 0.0365 — 꼬리 제거 실증. climb 창발이 50 iter 내 기각되는 시그니처 확인.
**단점:** 단독 기여는 보조적 — **지배 요인은 plant 일관성**(A0′도 96.5%). 감쇠 커브는 분석값(실측 캘리브레이션은 annotator 버그로 pending).
**결과:** deterministic 200-ep eval **100.0%**, d_xy_min 0.665m. (drop_impact_error 4.59m는 이후 exp_016에서 **지표 의미론 버그**로 판명 — 보상 문제 아님, Rule 21.)

## 9. Isaac exp_017 Stage A — 밀집 CCIP 조준 보상 (2026-07-06, Rule 22)

$$r_{aim} = w_{aim}\cdot\bigl(1 - \tanh(e_{aim}/s)\bigr) \quad (referee와\ 동일\ aim\_err,\ 기본\ w{=}0{=}\text{off})$$

**목적:** 보상 변경 **단독**으로 release_rate@0.2m을 6% 위로.
**결과 (det 200-ep):** 기준선 2.5% (학습 내 12→3.7% **단조 하락** — 근접 최적화가 릴리스 능력을 능동 파괴) → v1(w=1) **5.5%** (방향 실재하나 p≈0.13) → v2(w=2, knee 1.0) **3.5% 회귀** (수동 소득화, σ 1.55). **판정 (b): 밀집 조준 보상만으로는 릴리스를 못 올림.**

**구조 원인 3종 (Rule 22):**
1. $\gamma=0.995$ 할인이 +100 도달 지연(=감속·정밀 조준)을 벌함
2. CCIP가 탐험 σ를 낙하시간 ×1.53s만큼 증폭 → dense 그래디언트 평탄화
3. 성공(근접) 조기 종단이 조준 구간 자체를 제거

**장점:** 5-lens 사전 적대 검증으로 w=2 duty-cycle 펌프 PV를 예고 → w=1 개시 (헤지 적중). 판정 기준을 deterministic eval로 명문화(학습 내 지표는 σ-지터에 가려짐, Rule 22c).
**단점:** 문제의 소재가 보상 계층이 아니라 **종단 구조**에 있음을 우회 못 함. $w_{aim}$은 Phase 2+ 이월 금지(residual 채굴 경로).

## 10. Isaac exp_018 Stage B — 릴리스-종단 구조 (2026-07-06, Rule 23)

보상 항 추가가 아니라 **종단(termination) 의미론 교체**: 근접 종단(d_xy≤0.8 → +100) → **릴리스-발화 종단** (referee 발화: aim_err≤0.2m ∧ alt>1m → success +100).

**결과:** B0(보상 = Stage A v1 그대로, 종단만 교체): 학습 내 release **23→99.6% 단조 상승** — Stage A 하락의 정확한 반전 → **잘림(조기 종단)이 지배 요인 인과 확정.** det 200-ep **100.00%, drop err 0.125m**, 호버-드롭 수렴(종단 속도 0.11m/s — #8의 속도 캐리 4.6m 소멸).
**장점:** 자동 발화 referee가 탐험 노이즈를 +100 샘플러로 전환(발견 메커니즘) · γ-할인 역전(감속이 +100을 버리지 않음) · **aim 보상은 잉여로 판명**(w 0/1.5 모두 100%) — 보상 최소주의 달성.
**단점/주의:** 호버-드롭 전략의 바람 강건성 미검(Phase 2/Stage C 몫). Phase-2 release_tolerance 0.5 vs referee 0.2 정합 필요. done-flag alias 버그(`.clone()` 필수, Rule 23d)를 적대 검증이 사전 차단.

## 주요 결정 & 발견 (횡단 교훈)

- **밀집 보상의 3대 함정이 반복 재발:** ① 신호 소멸(지수 machine zero, Rule 4) ② 착취(milking/farming — 정지·고도 채굴, Rule 17·18) ③ 종단 트랩(페널티 해자·댐핑 반경 침범, Rule 10·16). 새 밀집 항은 **게이팅 + 반경 정합 + 사전 적대 검증(farm PV 계산)**이 표준 절차.
- **보상으로 풀 문제 vs 구조로 풀 문제의 구분이 최대 수확:** exp_017→018이 인과 실험으로 확정 — 릴리스 능력은 보상 shaping(judgment b)이 아니라 **종단 의미론**(23→99.6% 반전)의 몫. γ-할인·조기 종단·σ 증폭은 보상 가중치로 못 이김.
- **보상 공식 변경 → 반드시 Fresh Start** (replay buffer의 구 보상이 critic 오염, Rule 4) — v13/v15 모두 준수.
- **판정은 deterministic eval로** — 학습 내 지표는 탐험 σ와 plant 아티팩트에 가려짐 (Rule 22c, exp_013 vs 014).
